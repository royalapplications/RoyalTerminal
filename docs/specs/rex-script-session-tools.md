# Scriptable session layout and discovery

These operations extend [session events and block methods](./rex-session-observation-and-block-calls.md). They are an independently specified subset of the [Rex Lua API](https://www.superlogical.com/rex/docs/reference/lua), not wire-compatible replacements. `api describe session.METHOD` returns the exact RoyalTerminal contract. Both trusted script hosts expose the corresponding `rex.session` methods.

| Operation | Scope and behavior |
| --- | --- |
| `help`, `list_blocks`, `list_clients`, `describe_block` | A session reader can discover method schemas, enumerate blocks including hidden/exited ones, list only this session's attachments, and identify the block creator and supported method names. Discovering a method does not change the token's rights. |
| `move_block` | Move a terminal beside `target_id` on the left, right, above (`up`) or below (`down`). Both must belong to the same session; the target must be tiled. The fraction is the moving block's share, even when inserted second. |
| `swap_blocks` | Swap complete placements of two blocks; floating bounds travel with their positions, not the processes. |
| `resize_pane` | `orientation` is `horizontal` (left/right) or `vertical` (above/below). Modify the nearest split on that axis along the selected block's ancestor path. `ratio` is the new fraction of the child subtree **containing** the selection. A missing matching divider is a conflict, not a silent success. |
| `resize_layer` | Set the `x`, `y`, `width`, `height` of an already floating block, in integer ten-thousandths of its window. Refuses to convert a tile into a float implicitly. |

All four structural mutations require the administrator capability and accept `expected_revision`. A concurrent edit produces a conflict and is never blindly retried. No terminal byte, VT event, input lease or process restart is generated by moving a divider. The integration test in `scripts/workspace/smoke-session-tools.py` checks PID and stream sequence before and after moving three live processes.

```lua
local s = assert(rex.session.view{})
local b = assert(rex.session.describe_block{block_id = rex.block_id})
assert(rex.session.resize_pane{
  block_id = b.id, orientation = 'horizontal', ratio = 0.65,
  expected_revision = s.revision,
})
```

### Public JSON versus private RPC

`rex.json.encode` and `decode` implement the same rules in a CLI script and the operator's `init.lua`. An empty table is an object, a dense positive-integer table is an array, and other tables with representable string/numeric keys are objects. JSON null decodes to Lua `nil`, compacting arrays and omitting object fields; private IPC frames retain their own null marker. Invalid input returns `nil, error`. The codec rejects invalid UTF-8, unpaired surrogate escapes, duplicate JSON names, unsupported types, cycles, and numbers outside the finite Lua number range. Limit: 256 KiB and 64 nesting levels. Pretty output uses `{indent=true}`. No additional OS process or network call is required by the codec.
