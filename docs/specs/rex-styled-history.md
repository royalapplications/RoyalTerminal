# Reading restored terminal styles in a browser

An ordinary xterm attachment still owns its native scrollback. After a replay gap, RoyalTerminal's Wasm worker owns both the managed parser and retained screen cells. **History → Show terminal colors** renders those cells at a frozen point in time. The live terminal continues applying output in order. Search switches back to the plain transcript and selects the actual matching text. Closing the dialog, detaching or failing the connection drops the view. A new history dialog takes a new cut.

The plain and styled exports are synchronous operations in one worker message: no queued resize, output or alternate-buffer switch can intervene. Primary history includes the retained primary buffer; alternate history exposes only the current alternate viewport. The renderer preserves physical row breaks, resolved 24-bit foreground/background, inverse cells, bold, italic, dim, conceal, underline style/color, overline and strikeout. It does not animate blinking, execute escapes, attach links or load embedded images. Only literal text and bounded numeric display attributes cross the boundary; terminal-supplied markup is never assigned to `innerHTML`, a URL or a CSS string. This is not a bit-for-bit import of xterm's historical scroll position, terminal font shaping, or raster graphics.

Budget: at most 1,048,576 cells, 32,768 styled runs, 4,096 UTF-16 units per run, and 4 MiB encoded style data. The plain transcript remains readable when style generation exceeds its budget. The browser validates the payload and materializes at most 48 physical rows and 2,048 runs per page rather than creating spans for the entire transcript. Search covers the whole frozen plain transcript, not just a visible page.

The Chromium/real-process checkpoint test forces journal eviction, reconstructs an unfinished UTF-8 code point, checks the computed CSS of a colored old line, checks that an OSC 8 URL and literal `<img>` do not become active DOM elements, navigates pages, and switches to the alternate buffer without exposing primary history.
