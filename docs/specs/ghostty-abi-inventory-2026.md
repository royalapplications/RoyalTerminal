# Ghostty ABI binding inventory

Generated by `scripts/audit-ghostty-abi.py` from the pinned native
`ghostty_type_json` manifest and all public VT headers. No .NET reflection.
Regenerate with a freshly built native package; `--check` rejects stale output.

Types: **159** (6 alias, 71 enum, 20 opaque, 1 packed, 56 struct, 5 union).
Callback signatures: **27** (including four allocator vtable entries).

Header-only constants: **17** modifier/Kitty-key flags and **43** terminal modes (packed value, mode number, ANSI flag).

All enum members are named compile-time C# references compared with the runtime
manifest's numeric values; enum-width sentinels are checked as `int.MaxValue`.
Struct/union size, alignment, field offsets and field sizes are checked. Reserved
union padding is represented by explicit struct size (and its native zero offset).
Read/write callback auto-properties are checked using distinct constructor
markers at their native offsets. Opaque handles are `nint`; aliases/packed cells
are checked at their managed scalar width. The runtime type/member counts make
upstream additions fail validation until reviewed. Callback parameters/returns,
Cdecl, one-byte bool marshalling and allocator function-pointer signatures are
source-audited; raw typed pointers represented by `nint` remain pointer-width
ABI equivalents, not claims about ownership. Runtime ownership tests are separate.
